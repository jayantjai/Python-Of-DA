# Python-Of-DA
Python Basic and Intermediate for Data Analysis.
 This file contains Some of the Python operations which are useful in Data Analysis. It contains:

 1) Python strings:
    use of len() to find length of the string.
    Use of Count() to find the number of times any word appears in the string. This is generally used to check data quality.
    Use of String Transformation Methods:
     1. Use of replace() to change any character to some other value. It is used to remove unnecessary things from our data.
     2. Use split() to split our data values on the basis of a separator. It is used to separate the required values from our data. It gives the output in the form of a list
